# DTS:X Ultra for Nubia Tiro

Complete native DTS:X Ultra integration snapshot for the Nubia Tiro device tree.

Included:

- DTS:X Ultra privileged APK and framework JAR
- DTS native shared libraries
- Complete DTS tuning database, profiles, accessory files and licenses
- Qualcomm audio effects configuration
- Tiro mixer path adjustments
- Product makefile integration and DTS compatibility properties

The files retain their Android source-tree paths below the `source/` directory.

Branch: `dts-ultra`
